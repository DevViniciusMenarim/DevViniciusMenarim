Sou estudante de Engenharia de Software na Universidade Positivo, em Curitiba, com conclusão prevista para o fim de 2027. Desenvolvo aplicações web da interface ao banco de dados e busco estágio em desenvolvimento de software.

## Projetos

### 🎬 [Film Catalog](https://github.com/DevViniciusMenarim/Film-Catalog)

Catálogo para descobrir, pesquisar e organizar filmes. Implementei um modo de demonstração que funciona sem chave de API, a integração opcional com o TMDB e a persistência de favoritos e lista pessoal em MySQL.

**Tecnologias:** React, Node.js, Express, MySQL e Docker.

### ✅ [Task Flow](https://github.com/DevViniciusMenarim/Task-Flow)

Aplicação para organizar tarefas e pessoas, com subtarefas, prazos e indicadores de progresso. Desenvolvi a interface em React/TypeScript e a API em ASP.NET Core; os filtros de tarefas podem ser compartilhados pela URL.

**Tecnologias:** React, TypeScript, ASP.NET Core, SQL Server e Docker.

Os dois repositórios incluem diagramas de arquitetura e instruções para executar com ou sem Docker.
